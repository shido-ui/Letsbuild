# Changelog

## 0.1.0 — ModuleIQ

### Completed
- Structured knowledge ingestion and canonical storage.
- Global search with FTS5/LIKE fallback and source references.
- Persistent Practice Engine and adaptive learning.
- Review Center and analytics.
- Versioned JSON data portability with AI credentials excluded.
- Provider switching and AI disconnect without losing canonical knowledge.
- Local workspace data-isolation boundaries and baseline security headers.
- Installable Android-friendly PWA shell with offline application shell.
- SQLite WAL/concurrency tuning, gzip responses, and hot-path indexes.
- Ingestion failure/recovery lifecycle and manual retry.
- API end-to-end journey coverage.
- Full regression and production-hardening gates.

### Release contract
- AI is optional and replaceable.
- Canonical knowledge remains durable when providers are disconnected.
- Production deployments require explicit credential encryption, CORS, and host configuration.
