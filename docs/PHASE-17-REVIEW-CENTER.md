# ModuleIQ Phase 17 — Review Center
Phase 17 makes Review Center a persistent workflow over canonical database objects.
- Persistent knowledge-base-scoped review queue.
- Idempotent open flags for the same entity.
- Resolve/dismiss status preserves history.
- REST list/create/update endpoints.
- Question Detail can create a persistent review item.
- Full backend test suite is the verification gate.
